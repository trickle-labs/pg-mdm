# Build your first customer golden records

The complete, updated lesson is now [Your first customer golden records](docs/tutorials/first-entity.md). It follows the current 0.15.0 demo preview, includes a reproducible installation route, and takes you from four source rows to three customers with stable identities and expected query results.

Start with [Install pg_mdm](docs/how-to/install.md) if you have not prepared a PostgreSQL 18 environment. After the first lesson, continue with [Inspect and refine a golden record](docs/tutorials/inspect-and-refine.md), or use the [documentation home](docs/README.md) to find task guides, reference material, and explanations.
